# Security Policy

## Supported versions

Until `v1`, security fixes are provided for the latest published `v0` release only. After `v1`, the supported-version policy will be documented here.

## Reporting a vulnerability

Please use this repository's GitHub **Report a vulnerability** form under the Security tab. Private vulnerability reporting must be enabled before the repository is made public.

Do not open a public issue for an unpatched vulnerability. Include a description, reproduction steps, affected versions, and any known mitigations. We will acknowledge receipt and coordinate disclosure after a fix is available.
